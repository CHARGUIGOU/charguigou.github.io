{%- comment -%} IMAGES DE LA GALERIE construites depuis le front matter (page.gallery). Une ligne = une chaîne : fichier | légende | recadrage - fichier : nom du fichier (ex : Ralph_Breaks_the_Internet_Dutch_1.jpg). L'adresse complète est construite à partir de _data/images.yml. Une URL complète (http...) est aussi acceptée telle quelle. - légende (facultatif) : texte affiché au survol de la miniature et sous l'image ouverte (aussi utilisé comme alt). - recadrage (facultatif) : partie de l'image gardée dans la miniature carrée : north (haut, par défaut), center, south. HÉBERGEUR (front matter de la page) : - rien → Cloudinary (base + presets.gallery_thumb ; plein écran : gallery_full s'il est écrit, sinon l'image d'origine) - gallery_host: "imagekit" → ImageKit (dossier posters ; réglages "gallery_imagekit" de images.yml) - gallery_base: "https://.../upload/" → autre base de type Cloudinary (rare) - gallery_full (facultatif) : remplace le réglage plein écran de l'hébergeur choisi, dans la syntaxe de cet hébergeur. {%- endcomment -%} {%- assign g_full = page.gallery_full | default: "" -%} {%- if page.gallery_host == "imagekit" -%} {%- assign g_base = site.data.images.gallery_imagekit.base -%} {%- assign g_thumb_tpl = site.data.images.gallery_imagekit.thumb -%} {%- if g_full == "" -%}{%- assign g_full = site.data.images.gallery_imagekit.full -%}{%- endif -%} {%- else -%} {%- assign g_base = page.gallery_base | default: site.data.images.base -%} {%- assign g_thumb_tpl = site.data.images.presets.gallery_thumb -%} {%- endif -%} {%- for g_row in page.gallery %} {%- assign g_f = g_row | split: "|" -%} {%- assign g_file = g_f[0] | strip -%} {%- assign g_cap = g_f[1] | default: "" | strip -%} {%- assign g_pos = g_f[2] | default: "" | strip -%} {%- if g_pos == "" -%}{%- assign g_pos = "north" -%}{%- endif -%} {%- if page.gallery_host == "imagekit" -%} {%- if g_pos == "north" -%}{%- assign g_pos_h = "top" -%}{%- elsif g_pos == "south" -%}{%- assign g_pos_h = "bottom" -%}{%- else -%}{%- assign g_pos_h = g_pos -%}{%- endif -%} {%- else -%} {%- assign g_pos_h = g_pos -%} {%- endif -%} {%- if g_file contains "://" -%} {%- assign g_thumb = g_file -%}{%- assign g_big = g_file -%} {%- else -%} {%- assign g_thumb = g_base | append: g_thumb_tpl | replace: "{pos}", g_pos_h | append: "/" | append: g_file -%} {%- if g_full != "" -%} {%- assign g_big = g_base | append: g_full | append: "/" | append: g_file -%} {%- else -%} {%- assign g_big = g_base | append: g_file -%} {%- endif -%} {%- endif -%} {%- assign g_alt = g_cap | default: page.film | default: page.title %} {%- endfor %}
