{%- comment -%} IMAGES DE LA GALERIE construites depuis le front matter (page.gallery). Une ligne = une chaîne : fichier | légende | recadrage - fichier : nom du fichier sur Cloudinary (ex : Beauty_and_the_Beast_2_German_DVD.jpg). Le début commun de l'URL (https://res.cloudinary.com/dofvjifeo/image/upload/) est ajouté tout seul ; pour une autre base, écris gallery_base: "https://.../upload/" dans le front matter. Une URL complète (http...) est aussi acceptée telle quelle. - légende (facultatif) : texte affiché au survol de la miniature et sous l'image ouverte (aussi utilisé comme alt). - recadrage (facultatif) : partie de l'image gardée dans la miniature carrée : north (haut, par défaut), center, south. - gallery_full (facultatif, front matter) : réglages Cloudinary pour l'affichage plein écran, ex : gallery_full: "w_1600,q_auto:best" (pour les très grandes images ; sans lui, l'image d'origine est utilisée).
